Paper-trading record, by rule

Closing-line value (CLV): how much better our price was than the closing price, in points of win probability for moneylines and points of total for over/unders. It settles far faster than profit. Moneylines: above about +2.5 on average over 150+ bets is real evidence. Totals: above about +1 point. "Flat return" bets $1 on every pick; stakes are sized on a shrunk, realistic edge and can be zero.

What's new in v2

The October model knew only results, rest and Elo. Version 2 adds who is actually available, travel and time zones, a drifting home-court edge, the point spread and total, and five learners blended by an ensemble that re-weights itself every night.

Run it live

The live system runs in the cloud on GitHub Actions every 5 minutes: it pulls ESPN lines and injuries, places and settles paper bets, retrains nightly and reruns the opening-line study weekly. This page checks for new data every 30 seconds. It can also run on your own computer, from a terminal or the desktop app.

From a terminal

Same steps by hand. Needs Python 3.10 or newer.

pip install -r requirements.txt
python -m nba_edge setup        # history from GitHub, ~2 min
python -m nba_edge backtest     # optional: rebuild these charts
python -m nba_edge live --once  # backfill 2026, train, predict today
python -m nba_edge live         # keep running every 10 minutes
python -m nba_edge serve        # this dashboard at localhost:8000

Optional: set ODDS_API_KEY (free at the-odds-api.com) to pull every US book's price and bet the best one.

Method

Rules were fixed on the 2011-12 and 2012-13 seasons before any test season was scored.

Pipeline

    Limits of this study

    • The historical odds are one moneyline per game, close to the closing line. The market already contains the injury news by then, so this backtest is the hardest possible test. The live system stores opening and every later line, so it can test early betting, where an edge is likelier.
    • Player availability before 2024 comes from box scores: a player counts as out if he was inactive or listed with an injury, rest or personal reason. A first version counted anyone who did not log minutes as out; that leaked the game's flow and produced a fake 8% return, so it was removed.
    • The free player archive stops after 2023-24, so 2024-25 and 2025-26 are tested without lineup data. The live system fills this gap from nba_api or ESPN box scores.
    • Tonight's injury chances are rough base rates by status (out 0%, doubtful 15%, questionable 55%, probable 90%).
    • Real betting adds limits, line movement and account restrictions that a backtest ignores. Sports betting is restricted in Washington. This is a research project, not betting advice.
